# Portal BravoNexo

Endereço de destino: https://bravonexo.github.io/

Somente links para os aplicativos existentes:

- Gestão de Serviço: https://bravonexo.github.io/guarda/01gbm/
- Permutas: https://bravonexo.github.io/permutas/01gbm/
- Controle de RAS: https://bravonexo.github.io/ras/01gbm/

Os links abrem em outra aba ou janela, conforme o navegador, com
`noopener noreferrer`. Não há incorporação por iframe, login unificado,
redirecionamento automático ou alterações nos aplicativos.

O portal funciona com HTML e CSS, sem JavaScript, bibliotecas externas,
consultas a APIs, cookies, dados pessoais ou service worker. Não modifica
o armazenamento ou o funcionamento dos outros aplicativos deste domínio.

O layout prioriza o celular, com cartões inteiros como área de toque.
Os três ícones são carregados dos endereços públicos já usados pelos
aplicativos, sem modificar seus arquivos ou sua estrutura.
São exibidos em 80 px no celular e 104 px no computador.

O portal possui marca própria no cabeçalho e ícones PNG locais para a aba
do navegador e o atalho da tela inicial. Os arquivos em `icons/` fazem
parte da publicação. Nenhum service worker foi adicionado.
